# Реализация методов регрессии на примере датасета Ames Housing.
Проект по машинному обучению, посвящённый прогнозированию стоимости домов в городе Эймс, штат Айова.

## Описание проекта
Цель проекта — построить модель машинного обучения для прогнозирования цены продажи дома (`SalePrice`) на основе его характеристик.
В соревновании используется метрика **RMSE**, рассчитанная между логарифмами предсказанных и реальных цен (используем обозначение **RMSEL**):
\[
RMSE = \sqrt{\frac{1}{n}\sum_{i=1}^{n}
(\log(\hat{y}_i)-\log(y_i))^2}
\]

## Основные этапы проекта

### 1. Разведочный анализ данных (EDA)

- анализ распределения целевой переменной;
- анализ пропущенных значений;
- исследование категориальных признаков;
- поиск выбросов.

### 2. Предобработка данных
Для подготовки данных использовались:
- заполнение пропущенных значений;
- удаление признаков с большим количеством пропусков;
- обработка категориальных признаков;
- порядковое кодирование (`Ordinal Encoding`);
- One-Hot Encoding;
- `Pipeline`;
- `ColumnTransformer`.
Предобработка выполняется внутри Pipeline, что позволяет избежать утечки данных при кросс-валидации.

### 3. Baseline
 - Linear Regression

### 3. Построение основных моделей
 - Random Forest;
 - XGBoost;
 - CatBoost.
Для подбора гиперпараметров использовались **GridSearchCV** (Random Forest) и **Optuna** (XGBoost, CatBoost).

### 5. Интерпретация модели
Для анализа важности признаков использовалась библиотека **SHAP**. С её помощью исследовалось влияние отдельных признаков на предсказания модели.
